# Copeak Study 大学入試長文読解：新規教材作成・レビュー基準

最終更新：2026-11-13。本文・語彙・問題・解説を新規作成する際の共通基準。`draft` は制作段階、`published` は教材一覧で表示される公開状態を表す。教材を本番反映する際はデータの検証と公開ステータスの確認を必ず実施する。

## 1. 教材の構成と対象

- `data/reading/entrance/LXX-NNN.json` に1教材1JSONとして保存する。カテゴリーとレベルは `manifest.json` を参照する。
- 英検3級 170–250語、英検準2級 250–350語、英検2級 350–500語、英検準1級 500–700語、英検1級 700–950語、中堅私大 450–650語、難関大学 650–900語、国公立 700–1000語を基準とする。
- `word_count` はアプリと同様、`paragraphs[*].sentences[*].en` を空白連結して分割した結果と**完全一致**させる。
- 本文はすべてオリジナルで、読解力を要する展開（主張、具体例、対立、限定、結論）を含める。複数段落の内容を単に並べるだけにしない。

## 2. センテンスと辞書（必須）

- **全英文を意味単位のセンテンスに分け、同じ添字の `ja` に省略のない自然な日本語訳を登録する。** 逐語訳だけでなく、照応、否定、比較、因果、修飾関係を正確に訳す。
- `vocabulary` の各項目は `term`, `ja`, `definition`, `synonym` を揃える。原則として少なくとも40語・表現を収録する（長文に合わせて増やす）。ただし、英検3級は文章の短さと学習者の負荷に配慮して重要語彙20語以上とし、易しい単語を優先する。
- 登録語は**本文に実際に登場する形**を優先し、語形と品詞を文脈に合わせて訳す。英英定義は高校生が理解できる自作英文とし、別の単語の説明を誤登録しない。
- `social connection` などの複合語は、アプリの「単語タップ」で個別語が選択されるため、必要なら `social`、`connection` も登録する。
- 重要語彙を登録すれば「英→日」「日→英」「英英」の語彙クイズにも再利用される。意味が同じでも紛らわしい選択肢の発生に注意する。
- 本文中の情報だけでは不明な語義を憶測で補わず、辞書などで確認してから登録する。

## 3. 設問・根拠・発展演習（必須）

- 読解問題は従来教材で原則10問。拡張問題バンク（`question_bank_version: 2`）は、英検準2級以上で**最低20問の読解四択**、**最低20問の本文文脈語彙四択（`vocabulary_questions`）**を収録し、利用者が挑戦する読解問題数を10問・15問・20問・全問などから調整できるようにする。主旨、詳細、推論、語句の文脈上の意味、筆者の意図などを組み合わせる。
- 各設問に四択 `options`、0始まりの正解番号 `answer`、自然な `explanation_ja`、**根拠段落 `paragraph_ids`** を登録する。正解以外にも本文から区別できるもっともらしい誤答を置く。
- サポートモードでは選択した設問の根拠を本文から推定してハイライトするため、段落IDを必要以上に広げない。可能なら根拠となる一文を含む段落を指定する。
- `grammar`: `paragraph_id`, `sentence_index`, `focus`, `explanation_ja`。必ず `focus` が指定英文内に出現する。
- `discourse`: `paragraph_id`, `expression`, `role_ja`。表現が本文にあり、前後の因果・対比・追加・例示などを明確に説明する。
- `paraphrases`: `source`, `rewrite`, `explanation_ja`。`source` を本文に完全一致させ、言い換え後も意味を変えない。
- `cloze`: `paragraph_id`, `sentence_index`, `answer`, `options`, `explanation_ja`。正答表現は実際の本文に存在し、四つの選択肢は相互に異なる。

## 4. 出典と公開手順

- 実際の調査結果・数字・科学的事実には、確認できる**HTTPSの一次資料・信頼できる総説**を `source_links` に添える。`fact_notes` に何を確認し、何が架空の教育例かを明記する。
- 原文引用・転載はせず、独自に文章と質問を作成する。論争のある主張や研究結果は条件・限界も説明する。
- データ検証：JSONパース、語数とレベル帯、和訳件数、語彙の実在、四択と正解、根拠ID、演習の英文照合、出典リンク、重複チェック。
- 最終校閲：**英語の自然さ／日本語訳の忠実さ／正答の一意性／根拠ハイライトの妥当性／指導に使える解説**を教師が確認する。
- 作業中は `status: "draft"` とする。公開承認時は校閲とテスト結果を確認し、公開対象を `published` に切り替える。本番ブランチへのマージとVercelへのデプロイはユーザーから指示された場合のみ実施する。
