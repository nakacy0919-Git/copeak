# Copeak Study 大学入試長文読解 — 450セット制作・公開計画

更新: 2026-11-12

## 範囲
- テーマ：L01–L15（自然／歴史／科学技術／人間関係／国際社会／心理・哲学／経済・ビジネス／芸術・文化／文学・言語／教育・学習／法律・政治／医療・健康／宇宙・未来／婚姻・交友／倫理・道徳）
- 各テーマ30セット、合計450セットが**目標**。未作成セットを存在するように表示しない。
- 収録済みサンプル：L02-001、L12-001、L13-001 の3件。初回は機能検証用で、残り447件は未作成。
- Eikenと大学レベルは教材の訓練上の目安。実際の入試形式と語数は大学・年度・試験で異なる。

## 完成セットのデータ要件
1. 著作権に配慮した、独自に構成・執筆した英文。文体や段落を参考記事から近似コピーしない。特定大学の過去問本文を転載しない。
2. 数字・日付・固有名詞・歴史背景は一次情報や信頼できる資料で照合する。公的機関のリンクを `source_links` に記録し、確認した内容を `fact_notes` に残す。数値は集計年・母集団・定義・単位を確認する。
3. 英文と日本語を**一文ごと**に対応させる。英文の分割が不自然な場合は編集者が確認する。
4. 重要語彙は日本語訳・類義語・英英定義を含める。意味の違いが採点に影響する場合、類義語の使用条件も解説に記す。
5. 読解問題は本文根拠を示す `paragraph_ids` と、日本語解説 `explanation_ja` を持つ。4択は正文を単語だけ変えた選択肢にならないようにする。設問に要旨、詳細、推論、指示内容、文構造、言い換えを配分する。
6. ディスコースマーカーは本文で実際に使用されている表現に紐づける。対比、追加、例示、因果、言い換え、譲歩などの機能を明記する。
7. Paraphrasingは**本文中に現れる原表現**と、本文と同じ意味になる言い換え表現を対にする。抽象→具体、具体→抽象、同義語を偏りなく扱う。
8. 本文穴埋めは `paragraph_id`, `sentence_index`, `answer`, 4つの選択肢、解説を含める。正解語が原文に厳密に存在することを自動検証する。ディスコース＋一般語彙の両方を出す。
9. 国公立用には、4択に加えて要約・英文和訳・内容説明（手動採点できる模範解答・採点基準）を段階的に実装する。
10. 編集フローは `draft` → `reviewed` → `published`。編集者チェック前には本番で自動公開しない。

## 画面の動作
- トップに15分野・30目標件数、英検・大学レベル選択。収録済みの件数だけを表示。
- 本文表示＋一文ずつ訳の開閉・全訳表示。
- 読解四択と解説、サポートモードをONにした場合の根拠段落強調。
- 語彙一覧、英→日／日→英／英英定義→英単語クイズ。
- 文法解説、ディスコース、Paraphrasing、原文内語句の穴埋め。
- A4/B4、縦横、段組、文字サイズ、問題・解説、PDF・Wordの出力。
- 正誤の学習履歴は初期実装では端末内に保存。クラス集計・端末間同期は追加設計が必要。

## 品質ゲート
- `node --test tests/reading_entrance.test.mjs` で語数・文訳・選択肢・根拠段落・引用元・Clozeの原文一致を確認。
- iPad Safari の縦横表示、ポップアップ・日本語入力、B4印刷、Word表示は実機での最終確認が必要。
- 大量追加前に教員が設問難度・選択肢妥当性・データの出典をチェックする。
- バンドごとの語数は教材設計上の基準であり、英検・大学が定めた公式語数ではない。
