# Copeak Vocabulary Check v8.1 — 診断品質改善（開発ブランチ）

## 今回の変更

- v8の診断候補 **800件は変更せず保持**。学習用5,000件も変更なし。
- 下線が原則2～4語の問題、または核となる表現と日英の意味をセットで修正した候補を採用。
- 診断に使用する候補は **505件**（レベル別 85 / 70 / 61 / 60 / 63 / 58 / 55 / 53）。
- 明示的な短縮と正答変更が **80件**。これらは **教員による内容査読前の候補** です。
- 長い・意味対応を未確認の **295件は診断出題から一時保留**。元データには残します。
- 第1問は暫定レベル4から開始し、**第2問以降は回答のたびに出題レベルの目標を調整**。不正解なら少なくとも1段階低い目標、正解なら高い目標へ（端のレベルでは据え置き）。
- 再診断時は前回のレベルを初期値に流用せず、公平な暫定値から開始。履歴はそのまま保存。
- Quick 25問 / Deep 70問 / 4択 / 言語切替 / 効果音 / 履歴保存の仕組みを保持。

## 品質上の留保

**問題のレベル・正答・誤答選択肢は人による査読と実測難易度の校正が未完了です。**
英検級、CEFR、学年相当の公式判定ではありません。
v8とv8.1では出題範囲が違うため、レベルの単純比較はできません。
95%信頼区間など統計的な検証済み精度は示していません。

## ファイル

- `vocabulary-check.js`: 診断用核表現の選別、選択肢整合性チェック、回答ごとの適応
- `vocabulary-check.html`: v8.1表示、短縮・保留件数の説明
- `data/v8-1-focus-overrides.json`: 80件の編集提案（教員査読待ち）
- `tests/v8_1_quality.test.mjs`: 件数・下線・選択肢・出題・変更の安全性テスト

## テスト

```bash
node tests/v8_quality.test.mjs
node tests/v8_1_quality.test.mjs
```
