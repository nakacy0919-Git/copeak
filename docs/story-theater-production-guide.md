# Copeak Story Theater — 画像・音声制作ガイド

> 開発用ブランチ `feature/story-theater-20261118` の教材です。`main` / 本番には反映しないでください。

## 共通仕様

- **画像**: 16:9、WebP、推奨1920×1080。物語内で人物・衣装・季節・舞台の連続性を維持。画像内の文章・字幕・ロゴなし。
- **音声**: MP3、英語 en-US、一場面につき1ファイル。速度目安0.88–0.95×、明瞭で感情のこもった自然な朗読。背景音楽は入れない。
- **ファイル名**: 下表のパスを厳守。画像と音声は同番号を同じ場面に対応させる。
- **場面音声の原稿**: この文書にある英文を省略・変更せずに読み上げる。文中の台詞はナレーターが自然に読み分ける。
- **未登録時**: 画像は場面説明のプレースホルダー、音声はブラウザの音声合成で代替する。
- **ご注意**: レベル区分は学習目安で、検定団体が認定した教材ではありません。
